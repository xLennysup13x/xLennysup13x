# Career Portfolio

This area collects the supporting material that helps employers and collaborators understand how I work—not just what technologies I list.

## What to add

- **Project case studies:** the problem, intended users, design choices, implementation, testing, and lessons learned.
- **CV / résumé:** a current PDF, only when ready to share publicly.
- **Screenshots and demos:** evidence of working features, with links to source repositories.
- **Learning record:** relevant courses or certifications, clearly labelled as completed or in progress.

## Quality standard

Only describe features that have actually been implemented and tested. Never publish private customer information, passwords, API keys, tokens, or personal documents containing sensitive data.

## Current status

This is a portfolio structure. Add case studies and supporting documents as they are ready; do not present placeholders as completed work.
