# Portfolio review checklist

Use this list before treating the profile as a finished portfolio.

## Profile
- [ ] Confirm your name, location and contact links are current.
- [ ] Open every project link and confirm it points to the intended live project.
- [ ] Check project descriptions and technology lists against what you actually built.
- [ ] Add screenshots or short demos to projects where they help explain your work.

## Cybersecurity lab notes
- [ ] Review each write-up and edit it so it accurately describes your own lab work.
- [ ] Keep target addresses as `<TARGET_IP>` placeholders.
- [ ] Do not publish flags, passwords, tokens or other sensitive details.
- [ ] Keep testing limited to systems you own or are explicitly authorised to test.

## Repositories
- [ ] Add a clear README to each featured project.
- [ ] Remove secrets and local configuration files from public repositories.
- [ ] Include setup instructions and a short explanation of the project architecture.
- [ ] Add tests or screenshots where relevant.

## Final check
- [ ] Preview the profile README on GitHub desktop and mobile.
- [ ] Check spelling, formatting, links and image rendering.
- [ ] Revisit the profile whenever project status changes.
