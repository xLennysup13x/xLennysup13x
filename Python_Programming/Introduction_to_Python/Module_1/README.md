## How to document each lesson

- Keep the original lesson files in the matching folder.
- Add a short note about the concepts covered.
- Include runnable Python examples and expected output when useful.
- Use clear filenames such as `variables_and_types.py`.
- Do not include passwords, API keys, personal data, or virtual-environment folders.

The lesson folders are set up for organisation; the original lesson source files still need to be uploaded.
