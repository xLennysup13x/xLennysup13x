# Introduction to Python

Beginner lesson files and examples organised in Module 1. Lessons 1–7 contain Python source files; Lesson 8 currently contains notes only.

## Learning path

1. Open the [Module 1 overview](Module_1/README.md).
2. Work through each lesson in order.
3. Run the examples with Python 3 and change them to see what happens.
4. Write a short summary and try a small exercise for each topic.

## Run an example

From this folder, run a lesson file with Python 3. Quote filenames that contain spaces:

```bash
python "Module_1/LESSON_1/Python HOME.py"
```

These files are study material. Make sure you understand the examples, avoid adding personal information or secrets, and label your own exercises clearly.
